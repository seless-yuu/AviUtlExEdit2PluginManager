# AviUtlExEdit2PluginManager

AviUtlExEdit2のプラグイン管理ツール

## ユーティリティスクリプト

このプロジェクトには開発とビルドを効率化するためのバッチファイルが含まれています。

### 🔧 セットアップ

```bash
setup.bat
```
プロジェクトの初期化を行います。必要なディレクトリ構造、設定ファイル、サンプルコードを作成します。

### 🏗️ ビルド

#### 開発ビルド
```bash
dev-build.bat
```
デバッグ情報付きの開発ビルドを実行します。開発中のテストやデバッグに適しています。

#### 本番ビルド
```bash
build.bat
```
最適化された本番用ビルドを実行します。配布用パッケージの作成も含まれます。

### 🚀 実行

```bash
run.bat
```
ビルドされたプログラムを実行します。デバッグ版、リリース版、配布版から選択可能です。

### 🧪 テスト

```bash
test.bat
```
プロジェクトのテストスイートを実行します。C++テストファイルのコンパイル・実行や環境チェックを行います。

### 🧹 クリーンアップ

```bash
clean.bat
```
ビルド成果物や一時ファイルを削除します。クリーンアップのレベルを選択できます。

## 使用方法

1. **初回セットアップ**
   ```bash
   setup.bat
   ```

2. **開発サイクル**
   ```bash
   dev-build.bat    # 開発ビルド
   run.bat          # テスト実行
   test.bat         # テスト実行
   ```

3. **リリース準備**
   ```bash
   build.bat        # 本番ビルド
   ```

4. **クリーンアップ**
   ```bash
   clean.bat        # 不要ファイル削除
   ```

## ディレクトリ構造

```
AviUtlExEdit2PluginManager/
├── src/           # ソースコード
├── include/       # ヘッダーファイル
├── lib/           # ライブラリ
├── bin/           # ビルド成果物
│   ├── debug/     # デバッグビルド
│   └── release/   # リリースビルド
├── dist/          # 配布ファイル
├── docs/          # ドキュメント
├── config/        # 設定ファイル
├── plugins/       # プラグイン
├── tests/         # テストファイル
├── setup.bat      # セットアップスクリプト
├── dev-build.bat  # 開発ビルドスクリプト
├── build.bat      # 本番ビルドスクリプト
├── run.bat        # 実行スクリプト
├── test.bat       # テストスクリプト
└── clean.bat      # クリーンアップスクリプト
```

- Make
- 汎用的なコンパイラ (g++, cl)
